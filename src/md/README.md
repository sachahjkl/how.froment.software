# Intent

This folder holds the intent of the text: why it says what it says. It is not documentation of the site.
It follows [src/md](https://srcmd.org/).

The text argues one thing: a team works better when people answer for their work, when the repository is the
single truth, and when measurements, not opinions, judge. Everything else follows from those three.

The voice, set by the author:

- It attacks a target: agile as practised, where responsibility dissolves into following a method.
- Three sentences, three chapters: people answer, the repository is the truth, measurements judge.
- Opinions, stated plainly. No justifying, no defending, no selling, and no sentence about the text itself.
- Each piece is useful alone; together they make one coherent landscape. The text shows this by its shape and
  never says it.
- No personal metric. Measures describe the system, never a person.
