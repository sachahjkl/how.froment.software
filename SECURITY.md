# Security

This repository publishes a static site: no accounts, no forms, no cookies, no data about readers.

## Report a flaw

Use [private vulnerability reporting](https://github.com/sachahjkl/how.froment.software/security/advisories/new).
Say what you found, where, and how to see it. The answer comes within a week.

Only the current site and this repository are covered. For the threats that matter here, see
[THREAT_MODEL.md](THREAT_MODEL.md).
